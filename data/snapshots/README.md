# Quarterly Snapshots

Frozen point-in-time copies of `master.csv` taken at the end of each quarter.

These let us answer questions like "what did we know about Project X at the
end of Q2 2026?" — useful for tracking how cost estimates and schedule
forecasts change over time, and for fact-checking past reports.

## File naming

`YYYY-Qn.csv` (e.g., `2026-Q2.csv`)

Each snapshot is a verbatim copy of `master.csv` on the day the corresponding
quarterly report is published.

# Quarterly Reports

This folder will hold each quarter's written report, summarizing movement
in the database: newly completed projects, projects that slipped, headline
overruns, and changes in scope or status.

## Cadence

We aim to publish a report at the end of each calendar quarter, with research
focused on the preceding 3-month window plus any older projects that completed
or had material updates.

## Conventions

- File name: `YYYY-Qn.md` (e.g., `2026-Q2.md`)
- A matching frozen data snapshot is committed to `data/snapshots/YYYY-Qn.csv`
  the day the report is published.
- A git tag `vYYYY-Qn` is created at the same commit so the database state for
  that report is permanently recoverable.
